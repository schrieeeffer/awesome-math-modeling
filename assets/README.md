# 写作模板与记录表

这里提供可复制到项目中的论文骨架和工作记录。先根据当前赛题、比赛要求与参考论文确定结构，再选择需要的文件。

需要分章、BibTeX 和自动编译时，使用仓库顶层的 [LaTeX 论文工程](../latex-template/README.md)。本目录的 `latex/` 适合希望从单文件开始写作的项目。

## 文件一览

| 文件 | 用途 |
| --- | --- |
| `manuscript.md` | 论文提纲与各节填写提示 |
| `manuscript.docx` | 历史 Word 样式参考，使用时按当前规则和 Markdown 骨架更新 |
| `abstract.md` | 从已确认的方法与结果整理摘要 |
| `model-section.md` | 一问的完整论证结构，可按题数复制 |
| `ai-use-record.md` | 记录实际工具、用途、采纳与核验情况 |
| `latex/main.tex` | 可独立编译的单文件论文骨架 |
| `latex/references.bib` | 待填入真实引用的文献库 |
| `result-ledger.csv` | 记录数字的来源、单位、口径和核验状态 |
| `assumptions.csv` | 记录假设、依据、影响及验证方法 |
| `reference-profile.yaml` | 记录参考论文的结构、文风、版式及本项目采用方式 |
| `project-state.md` | 保存正式文件、配置和进度，便于中断后继续 |

## 使用方法

1. 将需要的文件复制到项目目录，按本题任务增删章节。
2. 写清推导、结果与验证，再整理摘要。正文中的关键数字与结果台账对应。
3. 根据参考论文调整表达和样式，按本届要求安排声明、附录及支撑材料。
4. 导出后检查页面和内容，清理草稿提示。

`〔待填：…〕` 表示尚未完成的内容；`R-ID` 和 `AI-ID` 分别是结果台账与 AI 使用记录的内部编号。它们用于工作记录，正文中的文献编号仍由引用系统管理。

进度记录和风格画像保存在工作目录，提交时按材料要求选择文件。

## Word 文件说明

`manuscript.docx` 保留早期样式，后续文字改进主要维护在 Markdown 和 LaTeX 中。新建 Word 论文时，可结合当前参考重新生成。

Word 骨架使用命名标题样式，章号是可编辑文字；复制章节后同步修改。表题使用 `SEQ Table` 域，增删表格后刷新域并核对题注与引用，最后重新分页检查。

模板来源、样式测量和历史验证记录见 [模板指南](../references/template-guide.md)。
