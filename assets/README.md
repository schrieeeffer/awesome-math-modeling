# 数学建模论文模板资产

这些是从本地写作资料提炼的工作模板，不是已核实的官方竞赛格式。先读取 `../references/template-guide.md`，并以适用竞赛的最新原始通知确定页数、匿名范围、摘要、AI 披露和提交要求。

需要默认启用 `.bib` 引用、按章节拆分并可直接编译的完整 LaTeX 工程时，复制仓库顶层的 [latex-template](../latex-template/README.md) 目录。本目录的 `latex/` 保留为原有精简骨架。

| 文件 | 用途 |
| --- | --- |
| `manuscript.md` | 从问题交付物到完整论文的主骨架 |
| `manuscript.docx` | 已用原生 Word 验证的可编辑论文工作模板，含标题样式和三线表 |
| `abstract.md` | 结果已确定后写摘要，逐问交代方法与答案 |
| `model-section.md` | 复制为任意一道问题的完整论证单元 |
| `ai-use-record.md` | 从开始工作即维护的 AI 使用事实记录 |
| `latex/main.tex` | 无外部图片、无私有字体、无伪造结果的可编译论文骨架 |
| `latex/references.bib` | 仅含填写说明的空引用库，不附赠未经核实的引用 |
| `result-ledger.csv` | 主技能提供的结果证据台账；论文数字必须能回溯 |
| `assumptions.csv` | 主技能提供的假设台账；假设必须说明影响和验证方法 |

使用步骤：复制到当前赛题工作目录；按真实问题数增删章节；先填结果、推导和验证，再写摘要；保留草稿中的结果台账 ID；核对通过后删除填写说明和占位符。不要把空模板、示例措辞或来源材料中的数字当成已完成的研究。

模板使用 `〔待填：…〕` 标记缺失信息。任何标记仍存在时，文件均为草稿。`R-ID` 是结果证据台账 ID 的示意写法，应替换为项目实际 ID；它不是最终论文的文献编号。`AI-ID` 同理，是 AI 使用记录中的交互编号。

Word 版以命名标题样式组织章节，章号是可编辑文字，复制章节后必须同步修改各级章号。表题使用 `SEQ Table` 域，增删或复制表格后刷新域并核对题注与正文引用；页码也使用原生域。空模板在本次 Word 环境中为 4 页，填入内容后需要重新分页和逐页检查。Word 版不是 LaTeX 版的像素级复刻。

模板保留了本地资料中有效的写作组织：摘要按问题展开，正文围绕每问组织“依据—模型—求解—结果—检验”，符号表含单位，附录列出可运行文件。删除了固定题数、预设模型、来源不明的数值、空泛优势、提前声明人工核验、统一检验套餐与未经核实的规则。具体取舍见模板指南。
