# 微网案例复盘：可迁移经验与专属假设

这份复盘整理自一个微网调度项目的建模、实验和论文工作记录。下文先列出该项目采用的假设，再归纳可迁移的检查方法。用于其他题目时，具体条件重新从题面、配置和实验中确定。

## 该项目采用的假设与评价范围

- 用户采用储能充电和放电效率各0.9，往返0.81。另一解释可做敏感性对照，不能因为外部AI更倾向单侧损耗就改掉正式主线。
- 原零点合同量x0、最终有效合同量x的计费权重为 `h=0.5*(x0+x)+max(x-x0,0)`：正式取消部分净退一半，增加部分按1.5倍，最终相对零点净结算一次，禁止卖电。h不是供电量。
- 必须保留的手算例：p=1时100→100账单100；100→20账单60；100→200账单250。预测价0.8、实现价1.2时100→20真实账单72。
- 主线纯SAA；lambda=0.2风险对照冻结保留。费率、833.33与5000/6、效率、终端状态、实时反馈、光伏信息权限必须读取实际配置；Q4不能顺便更改Q2/Q3。
- 8种更新组合、334天正式评价、五份Excel、指定日期小表、30页正文要求均属此案例，不复制成所有题目的默认要求。

## 15 类常见问题与检查方法

| 问题 | 应沉淀的判断方法 |
|---|---|
| 充放电效率歧义 | 说明损失在哪一侧，用方程落实，替代解释量化比较 |
| 10分钟时标错位 | 端点标签映射区间；全天总费用相同不保证指定槽正确 |
| 光伏剩余与售电 | 卖电必须有依据；不允许时明确弃用、充电及守恒 |
| “预测”附件不存在 | 历史实现值不等于给定预测，要自行构建当时可产生的预测 |
| 预报首小时空档 | 按发布覆盖和可观测性处理，不能在白天空档填零或偷看下一值 |
| 合同函数混淆 | 分清物理量、费用权重、净调整与逐次结算；主假设独立冻结 |
| Excel模板尺寸 | 检查真实表头、日期、144时段、日汇总、单位、空行与指定小表 |
| 跨日终端状态 | 连续传递实际SOC；水值按状态计量侧推导，不背乘/除效率公式 |
| 套利阈值误用 | 免费余光的边际成本与电网购电不同，不能用购电价阈值否定可行解 |
| 星期效应遗漏 | 检查可用历史的分组规律，预测改进再以实际总费用验证 |
| 功率与容量耦合弃光 | 解释弃用来源，不能仅用总容量估计可消纳全部余光 |
| 额定功率的计量侧 | 明确电网侧还是电池侧，检查效率换算后是否越限 |
| 首末相等误写固定值 | 题面等式不自动推出6000；固定初值作为附加约定要说明 |
| 极低电价与光伏抢容量 | 需要时间序列与约束解释，不能只看峰谷比作静态分类 |
| 寻找不存在的同价日 | 退化检验直接替换价格向量，而非在实际附件中强找匹配 |

## 论文与合作方式的经验

正文讲清关键答案和题面要求的汇总表，附录承载明细与代码。大表与小表按题目要求分别安排。附录标题要明写“附录”，摘要与正文分开计页；页数以最后一次编译的物理页核验。

原方案成熟时，外部AI核查只触发有证据的局部修复，不重新改合同、不删风险对照、不重写全部正文。术语解释和自然行文优先于华丽词藻；图表的专业感来自正确图型与单位、点身份、比较基准、可读字号，不来自工具品牌或生成式图片。

先完成实际可审阅产物再报告完成；“继续”、断电恢复、目录重命名、用户手动删改都依赖项目状态记录和实际文件核对。绘图变更同步图注、附录代码、PDF和Overleaf。最后发布以当前文件白名单为准，避免历史提示词文件和旧压缩包混入。
