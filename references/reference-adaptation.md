# 参考论文适配

给出一篇往年论文，就可以开始分析它的结构、文风和版式。随后结合当前赛题、实验结果与比赛要求，形成自己的提纲和写作样式。多篇参考同时使用时，先确定主参考，再吸收其他论文适合本题的部分。

## 准备材料

先读取已有对话和文件，再集中补问缺少的信息：

| 信息 | 可以怎样询问 |
| --- | --- |
| 赛题与要求 | 参加哪项比赛、哪一年？题目、附件、参赛要求和官方模板在哪个目录或链接？输出位置和格式是什么？ |
| 往年参考 | 希望参考哪篇论文？请提供链接、本地路径或文件。没有参考时，可以从现有资料选取，或先采用中性结构。 |
| 提交信息 | 本届是否需要封面、承诺书或登记表？所需队号、姓名、学校等由谁填写？ |

已有一篇完整案例时即可分析；用户只提供参考论文，也可以先整理它的写法。只改一段文字或一张图时，围绕该任务补问即可。

身份字段先按规则确认，再向用户收集。用户选择自填、暂无参考或暂不提供时，记录当前选择并继续可做的工作。可选参考等待回复期间，可以先分析题目和数据；影响定稿的必需材料则保留待确认状态。

## 阅读案例

| 材料 | 阅读方式 |
| --- | --- |
| PDF | 提取全文结构与段落，再查看摘要、普通正文、公式、图表、文献和附录的代表页面。版式依据实际页面判断。 |
| DOCX | 结合段落样式、页面设置、表格、题注和渲染结果分析。 |
| LaTeX | 查看主入口、文档类、样式与依赖，再核对编译后的页面；运行附带代码前先检查其用途。 |
| 网页链接 | 打开论文全文或可访问副本。访问受限时请用户提供文件，并说明已经读到的范围。 |
| 截图或扫描节选 | 记录可见特征和缺失部分，字体等难以确认的信息保留候选或未知状态。 |

长论文可以先梳理结构，再阅读各部分的代表段落。阅读记录写明页码、章节和覆盖范围；用户要求全文阅读时按该范围完成。

## 提取结构、文风与版式

| 方面 | 观察内容 |
| --- | --- |
| 结构 | 摘要或summary sheet、章节组织、假设与符号的位置、各问的衔接、验证、结论、建议书或信函、附录及篇幅分配 |
| 文风 | 面向的读者、标题命名、句子长度、术语密度、如何引出公式、解释数字、过渡和讨论局限 |
| 版式 | 页面与栏数、字体和字号、行距与缩进、标题层级、图表宽度、配色、题注、公式编号、引用及页眉页码 |

将观察写成可以照着执行的描述。例如：“先解释曲线变化，再引出状态方程；公式后说明参数；最后报告误差和适用范围。”这样的记录比“写得自然、严谨”更有用。

完整写作可用 [reference-profile.yaml](../assets/reference-profile.yaml) 保存风格画像，记录来源位置和判断把握。简单任务在工作记录中记要点即可。画像保存在当前项目中，未知字段填 `null`。

## 转成当前项目的写法

本届要求决定格式与提交内容，用户偏好和参考案例决定允许范围内的表达方式。逐项记录参考特征在本题中的处理：

| 参考特征 | 本题处理示例 |
| --- | --- |
| 由现象分析逐步引出模型 | 沿用论证顺序，换成本题的观测与推导 |
| 原稿分成五个模型章节 | 按本题任务与模型依赖重新安排章节 |
| 双栏正文或独立目录 | 核对本届要求后决定采用方式 |
| 摘要页、政策建议或信函 | 根据本届交付物设置对应部分 |
| 图表和配色 | 保留视觉层级，用当前结果重新绘制 |

有官方模板时，直接用其文件实现规定格式。只有案例PDF时，可重建可编辑版式，并说明近似项。需要起点时，选用 `latex-template/`、Markdown骨架或其他合适的文档工具。模板识别主要回答结构和样式如何实现，未必能确定原作者使用的软件或模板名称。

## 写作与校准

先根据本题证据生成提纲，再用一个模型解释段、一个结果段和一页含图表的页面校准风格。检查论证顺序、语气、术语密度和实际排版，调整后继续全文。参考稿之间存在明显分歧时，再就影响较大的选择询问用户。

采用参考稿的论证方法和表达节奏，用当前题目、模型及计算结果原创写作。参考稿中的模型需要重新判断适用性，引用回到原始来源核验。检查最终稿时，同时看答题是否完整、文字是否符合选定风格，以及页面是否满足本届要求。

## 身份与项目记录

实名封面、登记材料与匿名论文分别生成。匿名检查覆盖文件名、页眉页脚、批注、作者元数据和压缩包路径。用户自填的字段放在对应实名材料中，并在交付时说明。

队伍信息和私人材料留在当前授权项目内。下次更换比赛时重新核对规则与参考；用户希望长期沿用某种风格时，再将相应偏好保存为个人设置。
