# 从数学任务选择模型

本表是根据历年题型与建模验证要求形成的综合决策指南，不表示下列算法都在已审阅论文中使用。具体历史做法只按 case-evidence.md 或检索到的原页表述。不要因搜索命中模型名，就把该模型选为本题主模型。

## 先识别任务与信息条件

| 任务与关键条件 | 优先基线及升级路径 | 需要写清楚的数学对象 | 主要验证与常见误用 |
|---|---|---|---|
| 有限选项、排班、选址、配置、资源预算 | 可枚举小规模基线 → 线性/整数规划；含非线性时判断结构，再选连续优化或启发式 | 决策变量及其定义域、目标、容量/时序/逻辑约束 | 回代全部约束、与基线及可得界比较；遗传/退火求得较好解不等于已证明全局最优 |
| 多阶段库存、收益和决策依赖 | 阶段平衡基线 → 动态规划、分解或情景规划 | 状态、动作、转移、边界、成本累计、可观测信息 | 小实例枚举、终端边界、滚动情景检验；不能用决策时未知的未来信息 |
| 时间序列预测 | 持续值/季节性基线 → 趋势/回归/经典时序；数据支持时再用复杂学习器 | 时间粒度、预测步长、外生变量、切分与损失 | 按时间回测、按预测步长报误差；随机切分常高估泛化，短序列不自动适合深度网络 |
| 解释因素、估计关系或分类 | 描述分组 → 可解释回归/分类基线 → 有理由的非线性 | 因变量、特征、混杂因素、样本结构、类别代价 | 独立测试、残差/校准/类别指标；相关性不直接写成因果，重复样本不能跨训练测试泄漏 |
| 几何运动、光学、热学、流体或结构过程 | 几何/守恒/力学简化 → 微分方程或数值离散 | 坐标、量纲、初始/边界条件、状态方程、接触与碰撞条件 | 量纲、极限、守恒、网格/步长收敛及测量对照；不能只展示求解器运行成功 |
| 参数识别、设备标定、成像反演 | 可识别的简化解析关系 → 约束最小二乘或正则化 | 观测模型、未知参数、噪声、先验和约束 | 参数可识别性、残差、噪声扰动与独立校验；拟合优不必然意味着参数有物理意义 |
| 综合评价、排名、等级判定 | 先定义评价对象与指标含义，再定归一化和有依据的权重/距离规则 | 指标方向、评价主体、权重来源、缺失处理、类别边界 | 权重扰动、删指标/归一化方案变化、外部合理性；熵权是变异信息权重，不能自动当作实质重要性 |
| 网络路径、覆盖、匹配与调度 | 图与可达性 → 最短路/匹配/流或图上的整数规划 | 节点边含义、方向、距离/时间权、资源限制 | 连通性、路径合法性、服务时限、负载；欧氏距离不能替代题设道路时间而不解释 |
| 服务台、排队、拥堵或离散事件 | 简单容量/排队近似 → 离散事件仿真 | 到达/服务规律、资源、队列规则、初始状态 | 稳态/预热、重复仿真及不确定性、实测校准；一次仿真值不当作稳定均值 |
| 图像拼接、目标识别、空间匹配 | 可解释特征与局部匹配 → 全局一致性优化 | 像素/物理坐标、特征、匹配评分、几何约束 | 有真值时量化、无真值时一致性与人工可定位核查；美观拼图不足以证明算法准确 |

## 选模型时说明什么

短比较表就够：候选方案、它保留的题目结构、需要的数据、可解释性/求解代价、决定采用或舍弃的原因。不同模型可能回答不同分问，不强求在同一评分表里竞争。

复杂度增长要有对应问题。例如原模型不能表达整块地种植的离散约束，才引入整数变量；确定性方案对价格扰动很脆弱，才比较情景或稳健方案。不要在没有改善证据时称模型组合为“创新”。

## 把分问连接成论文

- “刻画—预测—优化”：前问输出的指标/参数进入预测；预测的区间或场景进入决策，而不是只传一个无误差点值。
- “标定—重建—检验”：先确定设备或系统参数，再重建对象；利用不参与标定的数据检验，避免闭环自证。
- “基础机制—额外约束—推广”：每次修改指出新增约束/机制，复用已验证部分，并报告对结果及计算代价的影响。
- “评价—筛选—配置”：先解释评分代表什么，再说明为何筛选门槛与配置目标一致；评分高不自动等于最优配置。

这些是可选组织方式。若题目各问独立，就保持独立，不虚构前后依赖。

## 来源中的可迁移经验

以源 S350fb28fb5bc 的出租车资源配置论文为例，PDF物理页1–4依次把“供求匹配”操作化为指标、比较政策情景，再进入时空分区补贴方案。这支持“先明确评价对象和操作指标，再写策略”的组织方式；其具体指标、假设和数值不能直接搬到新的交通题。页1的摘要数值只代表该文报告，未复算。

源 Sa49c83dbd8b8 的交巡警平台文章是期刊改写/刊载版本，PDF物理页1能读到管辖、调度、围堵等任务与0–1规划的对应关系。它适合启发“一个现实问题拆成多个数学对象”，不作为国赛提交版式依据；其正文文本层有字形缺失，进一步公式分析须看页面。

其他题型按 paper-archetypes.md 选择已记录案例，再阅读 case-evidence.md 的具体页码与阅读深度。题目名称相似只是检索线索，模型适配必须回到本题约束。
