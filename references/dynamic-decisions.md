# 预测驱动的动态决策

适用于调度、采购、库存和储能等问题。模型既要描述资源如何变化，也要说明决策时能知道什么、执行后怎样计费。效率、费率、时间粒度和终端条件从当前题目及已确认配置中读取。

## 分清变量和费用

先定义供给与需求、合同或计划量、状态、计费方式、优化目标和实际支出。例如，某个系数可能只用于算账，并不代表收到的实物数量；风险惩罚则用于比较方案，与实际支付费用分别统计。

合同模型应交代价格取自签约还是交付时点，取消和增加如何收费，调整是最终净结算还是逐次交易，以及是否允许出售。用无调整、下调、上调和预测价与实现价不同的手算例检查公式及代码。

分段函数要落实到求解模型。例如用 `u >= x-x0, u >= 0` 表示正部项时，需要目标中的正系数推动 `u` 取到下界，其他约束也要允许它取紧。负价或目标结构改变后，重新检查等价性，必要时采用精确分段建模。决策时尚无法区分的场景共享同一可执行决策；后续调整随新信息的揭示发生。

容量、功率、效率和状态量分别注明计量位置及单位。功率转为能量使用真实时长，首末状态相等与固定初末值分别表述。数据标签可能表示区间起点、终点或瞬时值，用首行、末行、跨日和指定时段验证映射；年度总量之外，还要检查逐段对应关系。跨问题沿用参数时保留原精度，调整则单独说明。

## 按当时可见的信息预测

为预测记录发布时点、目标区间、训练截止点和模型版本，明确实时反馈何时可见。联合样本只使用所有变量在当前决策前均已可用的历史记录。预测残差在真实值到达后才可加入样本库，历史预测保留当时发布的版本。

正价格的对数残差可以定义为：

```text
r[j,k] = log(p_real[j,k]) - log(p_hat_at_issue[j,k])
p_s[k] = p_hat_now[k] * exp(r[s,k])
```

第一式比较实现价格与当时发布的预测，第二式将已成熟的历史残差应用于当前预测。抽样时匹配发布阶段和预测提前量。零价或负价需要另选变换，并写清逆变换。样本不足时设置冷启动与回退方案；偏差修正明确窗口，并把系数为 0 的未修正方案纳入比较。

将小时预报转成更细时段前，先判断它是瞬时值还是区间均值，再选择插值或保持总量的分配方法。首个预报之前的空档根据当时可见的观测处理，左端点也应满足信息时序。核对非负性、夜间零值和能量含义。

场景诊断至少展示点预测、场景均值、分位数、覆盖率、极端倍率和裁剪比例。裁剪边界由决策前可用数据确定；是否将场景均值校准到点预测，取决于点预测是否代表条件均值。报告中分别解释名义覆盖率、样本覆盖率与条件校准情况。

## 连续执行与真实结算

滚动求解时固定已经执行的区间，向后传递实际状态和有效合同。若题目约定每日重置，写明重置条件；其余情况保持跨日连续。终端剩余资源的价值从状态计量位置和后续可行动作推导，并比较跨日近似的影响。

“未来价格是否可见”和“最终采用什么价格结算”分别确定。预测价或场景价进入决策，真实费用按题设结算价重算。引入新的价格机制时，先用同一实现价重结算旧策略，再比较新策略。

已知未来价格的分支作为信息对照：各场景使用同一条实际未来价格，需求与供给仍遵循各自的信息权限。若要将该对照称为下界，还需证明其可行域、目标及整个评价期的关系。

## 设计能解释收益的实验

在正式评价前确定候选方案、验证区间和选择规则。预测误差与决策效果分别报告：例如价格 MAE 改善说明预测更准，费用是否降低还需实际运行验证。总费用、应急支出、缺供、弃用和风险指标可一起呈现，以说明取舍。

要分离均值变化与联合结构的作用，可以依次比较原点预测、同一联合场景的均价替代和联合场景。相关性消融保留相同的边际样本，以整日轨迹为单位独立配对或用多个预先固定的种子打乱配对，保留日内时序。多个信息源可以用完整因素组合比较；若有 m 个可选更新时点，按研究需要检验 2^m 种组合。

样本平均近似（SAA）与风险目标分别列出。使用条件风险价值（CVaR）时，定义风险对象、置信水平、样本权重和惩罚系数，并同时报告实际费用。应急费用风险与总费用风险各有含义；计算总费用 CVaR 时，保留随场景变化的合同基准费用，否则尾部样本集合也可能改变。风险方案可以体现为增加部分平均成本、换取尾部损失下降。

## 从小例检查到完整评价

1. 用手算检查费用、时间映射、单位、守恒、上下界和极端情形。
2. 在小实例上精确求解并独立复算费用，核对线性化和信息约束。
3. 固定当前信息、模型版本和随机种子，只扰动未来实现值，检查预测、场景及优化系数是否保持不变。存在多重最优解时，从输入与系数验证，求解向量只作辅助。
4. 对原模块做回归和退化检查。直接替换输入构造已知情形，保留其他配置不变。
5. 完成全期评价和所需消融，保存未舍入明细用于账单与守恒检查。后续仅调整文字或图形时，可以复用这组结果。
