# 建模决策与证据流转

用于从题目进入可验证的模型，或定位已有方案在哪一步需要补证据。先按题目目标判断任务类型，再选方法；A/B/C 等题号不固定对应某一种数学模型。这里是由本地培训资料提炼并纠偏的工作规则，不是竞赛评分标准。来源编号见 [prompt-distillation.md](prompt-distillation.md)。

## 1. 把每一问变成一份可验收任务

逐问记录：原题要求及位置、输入文件/字段/单位、输出对象和精度、决策变量或待解释量、硬约束、软目标、前问依赖、验收方法。题目要求“给出方案”时必须交付可执行方案，只有目标值不够；要求“分析关系”时不要自动改为预测任务。

区分三类条件：

- **题目事实**：保留原文定位与数据口径，不当作可自由调整的假设。
- **推导得到的条件**：写出来自哪个定义、物理关系或逻辑条件，不能把“隐含条件”当作自由补题。
- **建模假设**：说明简化了什么、作用于哪条方程/约束、为什么合理、失效会影响哪个结论。不能靠假设删除题目的核心困难。

先画依赖关系再分工。例如 Q1 估计参数、Q2 优化决策、Q3 扰动评估，应传递 Q1 的估计区间与数据口径，而不只传一个点估计。没有依赖的小问可并行；有依赖时禁止混用不同版本参数。依据：W01 P014–P018；W10 P058–P074；W08 P151–P184。

## 2. 数据先回答能否支撑问题

先检查样本单位、时间跨度、测量单位、主键及重复记录、缺失分布、异常含义、字段生成时间。记录每次修改的字段、原因、规则、影响行数、修改前后统计；保留原文件。

| 情况 | 先做什么 | 不采用的捷径 |
|---|---|---|
| 缺失 | 判断缺失位置、成因与任务相关性；比较合理处理方案对结果的影响 | 按一个缺失率阈值直接删列；无法仅凭数据断言 MCAR/MAR/MNAR |
| 极端值 | 区分录入错误、单位错误与真实极端状态；真实事件有可能正是题目重点 | 一律按 3σ、IQR 或聚类标签删除 |
| 时间序列 | 明确预测时点与信息可用时间；按时间划分验证 | 使用未来数据插值、随机拆分导致前视泄露 |
| 同一对象多次观测 | 明确独立统计单位，按部署目标决定是否按对象分组划分 | 将同一对象的相邻记录随机分到训练与测试集 |
| 预测/分类预处理 | 在每个训练折内拟合插补、缩放、选择特征与目标编码，再变换验证数据 | 先对全量数据处理再交叉验证 |
| 特征构造 | 为每个特征写业务/物理含义与获取时点；检验是否有增益 | 强制制造衍生特征；使用结果产生后的字段 |
| 数据很少但有机理 | 先做单位、量级、边界、守恒与参数可识别性检查 | 以复杂学习模型补偿不可识别或信息不足 |

数据量“不够”应对应具体模型、有效独立样本数和验证目标，不能用统一样本数划线。训练/测试的要求适用于需要评估泛化的任务；确定性单位换算不需要虚构训练集。依据：W11 P041–P058、P087–P102；W09 P346–P363。分组划分、折内目标编码与适用范围是本 skill 的纠偏补充。

## 3. 选择一个能跑通的基线，再决定是否增加复杂度

候选模型通常保留一个基线和一至两个有明确理由的备选。逐项比较题意覆盖、数据条件、硬约束、可解释性、求解资源、验证方式。简单模型正确回答题目时可以作为最终模型；不要因为“国奖版”标签而强制更换。

具体任务的基线、升级触发条件、假设与回退判断见 [model-selection.md](model-selection.md)。先按目标和数据结构定位相应任务，再将候选方案放回本节的适配、资源与验证要求中比较。

这里是选型起点，不是算法白名单。加入一种改进须写明：**基线缺陷 → 改动位置 → 题目依据 → 可测增益 → 公平对比**。参数调节、算法改名和简单叠加不自动构成创新；改进失败也要保留记录。依据：W08 P052–P068、P253–P286、P450–P457；W12 P043–P048、P069–P073。

## 4. 让数学模型、代码和结果互相对得上

优化模型应完整列出变量定义及取值域、目标、全部约束、参数来源。方程或统计模型应明确输入输出、参数意义、误差项/随机性、初始边界条件。区分“构建模型”与“选择求解算法”，不能只罗列算法名称。

先验证一个小实例、边界情形或已知解，再运行完整数据。日志至少留存输入版本、环境版本、随机种子、参数配置、运行状态、结果路径。迭代求解还应记录终止原因、迭代数、计算时间以及可获得的界或 gap。未证明全局最优时写“当前找到的最好可行解”，不能把启发式收敛曲线当成最优性证明。

对结果执行独立核算：量纲与量级、变量域、约束残差、总量守恒、结果文件格式。正文只展示能说明求解正确性的关键中间量，完整迭代日志留在附件，不逐轮塞进论文。依据：W12 P062–P073；W08 P339–P355；W01 P488–P495。最优性措辞与独立核算是纠偏补充。

## 5. 验证什么结论，就设计什么实验

在看最终结果前确定评价指标、数据划分或场景、比较基线、可接受误差与资源预算。阈值来自题目要求、测量精度或实际决策容忍度；不要照抄“MAPE 小于 10% 就优秀”。

| 需要支持的结论 | 最小有用验证 | 不能据此推出什么 |
|---|---|---|
| 方案可行 | 逐条核算硬约束残差/违约量，检查输出决策 | 可行不等于最优 |
| 优化质量较好 | 小实例精确解或已知界；同预算基线对比；随机算法多次运行 | 无有效界时不能报告有保证的最优性 gap |
| 能预测未见数据 | 按时间/对象/空间依赖设计外部留出或交叉验证；与朴素基线同样本比较 | 训练拟合好不等于泛化好；时间序列不能机械随机 K 折 |
| 分类能满足目标 | 混淆矩阵及与误判成本相符的指标；不平衡时检查召回、精确率和 PR；必要时校准 | ROC-AUC 高不保证某个部署阈值的实际表现 |
| 排名稳定 | 扰动权重/指标处理方案，查看排名变化和关键方案是否翻转 | 一致性不是评价体系正确性的证明 |
| 机理数值解可信 | 守恒、边界、解析极限、步长/网格收敛与可用观测对照 | 数值收敛不等于真实机理已被验证 |
| 随机系统结论稳定 | 独立重复、初始化/预热影响、均值及不确定性区间 | 一条平滑曲线不能证明稳健 |
| 改动确实有效 | 同数据划分、同计算预算的基线/消融；记录增益与成本 | 多试几种后选择最好结果不等于独立验证 |

灵敏度分析应先找会影响结论且不确定的参数，再选有实际意义的扰动范围。局部导数有量纲；若用归一化系数，应明确分母与零值处理。离散决策可能发生跳变，应直接检查方案切换、约束违反和目标变化，不能只报一个线性系数。

检验失败时先定位数据、公式、实现或假设缺陷，再修正并在未污染的验证方案上复验。不能反复改阈值、删样本或选择随机种子“直到通过”；无法消除的失败应限制结论并如实报告。依据：W13 P041–P045、P085–P107；W08 P202–P218、P270–P303。此表对原文强制检验矩阵和任意阈值作了纠偏。

## 6. 给写作一个可追溯的交接包

每轮只更新一个结果主版本。保存以下最小字段，可用 Markdown/JSON；缺少证据的项写 `待计算` 或 `待核验`，不填“预期”数值：

```text
问题编号与原题定位：
任务要求与输出口径：
数据文件/版本/字段/单位及处理日志：
模型假设、公式、约束和参数来源：
运行命令、代码版本、环境与运行状态：
结果ID、值、单位、原始输出文件：
验证ID、数据划分/场景、基线、指标与局限：
图表ID、数据源、生成脚本、文件、拟支持的结论：
正文可写的结论及对应证据ID：
未解决问题与下一步：
```

摘要和结论从交接包生成；修改模型或数据后，使旧结果、旧图表及依赖它们的段落失效并重算。论文写作和图表审查见 [paper-review.md](paper-review.md)。交接思想依据 W10–W15 P029–P031、W18 P023–P050；证据 ID、版本失效机制是本 skill 的实现补充。

上述条目中，人口脚本的年份/年龄标签错位和红白组变量复用是可直接观察的静态不一致；`moni2.m` 的 a/β 对应关系还应回查论文符号定义。空候选、越界、非实根等是条件性风险，必须用相应输入验证，不能声称在原始数据上已经失败。对 `dtchi2rnd` 的记录是未解析调用，未据此断言 MATLAB 报错。

迁移历史代码时遵循：**读入口与依赖 → 核对变量/单位和假设 → 小例及边界检查 → 固定配置运行 → 独立核算 → 再写论文**。保留来源原件，适配代码另存；原论文能运行过或文件名标“优秀”都不能替代当前复现。完整只读抽查记录位于原项目 `_distillation/workflow_work/code-audit.json`。
