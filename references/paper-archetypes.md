# 按任务选择论文结构

用户指定往年案例时，先按 [reference-adaptation.md](reference-adaptation.md) 提取该案例结构。本文件的结构类型只在需要补位时选用；“推荐目录”和段落骨架不是必须逐项套用的模板。

这些结构由本地同题论文的对照选读抽象，案例编号见 [case-evidence.md](case-evidence.md)。它们是原创组织框架，不是固定模型答案。先判断题目输出与证据类型，再选择一条主结构；复合题可以共享数据和验证层，按分问嵌入不同结构。

## 快速路由

| 题目核心输出 | 主结构 | 首先要明确 | 主要验证 |
|---|---|---|---|
| 分配、排班、检测、种植、路径、选型方案 | A 约束优化与决策 | 决策变量、目标口径、约束、信息可得时点 | 可行性、基线、最优性范围、情景扰动 |
| 浓度/销量/时间预测、分类、关系估计 | B 数据分析与预测 | 样本单位、目标变量、数据划分、指标定义 | 留出/滚动验证、误差分布、泄漏检查 |
| 受力、温度、运动、光学反演 | C 机理与数值计算 | 几何/守恒关系、初边条件、参数可辨识性 | 量纲、极限情形、残差、步长/测量误差 |
| 综合得分、质量分级、供应商选择 | D 评价与排序 | 评价对象、方向、可比尺度、权重来源 | 权重/指标扰动、排名稳定、外部合理性 |
| 队列、随机策略、交通仿真、多主体 | E 随机过程与仿真 | 状态、事件、转移规则、可观测信息 | 小例、重复运行、区间、初始化/时长敏感性 |

## A. 约束优化与决策

推荐目录：任务拆解 → 数据映射与参数 → 决策变量 → 目标函数 → 逐条约束 → 完整模型 → 求解配置 → 方案表与目标值 → 可行性和基线对比 → 不确定条件下的修正。

每问内部使用以下证据顺序：

1. 先区分“能否做/做多少/何时做”，为二元、连续、整数变量分别定义。
2. 给出收益或成本的计算口径。销售收入、总利润、单件期望利润、累计利润不能混用。
3. 将题设约束逐一映射到公式和程序检查项；软偏好与硬条件分开。
4. 方案表回答具体动作，指标表报告结果质量；完整大表放交付文件，正文给代表行和定位方式。
5. 报告与可行基线相比的提升、计算时间、随机算法重复波动；没有全局证据则写“当前搜索范围内最佳可行方案”。

原创摘要骨架：

> 以〔变量〕为决策变量，以〔带单位和时间范围的目标〕为优化目标，结合〔关键约束〕构建〔模型类别〕。采用〔算法/求解器〕获得〔可执行方案及目标值〕，全部〔约束数或类别〕满足要求。相较〔基线〕，〔指标〕改善〔数值〕；在〔扰动情景〕下，〔方案切换/性能变化〕。

同题差异：2024 C 遗传算法稿先给确定性方案，再加均匀扰动与灾害因素；随机优化稿对比求解器和贪心，再引入场景。可学习“确定→不确定→关联扩展”的组织，不能把两稿利润直接比较为算法优劣，因为模型假设、参数和求解设置不一致。[P04、P05]

## B. 数据分析与预测

推荐目录：样本与目标定义 → 数据质量及处理 → 描述性发现 → 候选模型与选择理由 → 训练/估计设置 → 留出验证 → 预测结果及区间 → 误差来源与使用范围。

正文要连续解释：观察到何种曲线/分布 → 为什么采用此函数或模型 → 如何估计参数 → 如何证明对新样本仍适用。探索性图不等于预测验证，拟合优度不等于泛化精度；数据处理参数必须仅用训练数据拟合。

原创结果骨架：

> 在〔独立划分方式〕下，模型的〔指标〕为〔数值〕，相较〔简单基线〕变化〔数值〕。误差主要集中于〔范围/群体〕，而在〔范围〕内较小。由此采用该模型预测〔目标与期限〕，并给出〔区间/场景〕；对训练范围之外的〔条件〕暂不外推。

同题差异：2016 C 两稿分别以多项式关系和指数关系描述放电曲线，都把单电流拟合扩展到电流参数变化，再处理衰减。值得学习的是层次和物理范围，不能因摘要 R² 较高就认定模型优胜，更不能照抄时间单位和误差值。[P21、P22]

数据结构示例：2022 C065 先解释成分数据与不配对观测带来的限制，再安排分类和聚类。写作时同样应把样本对应关系、数据变换及分析目的说明白；聚类的相似性发现不能当作监督分类的验证成绩。[P32]

## C. 机理与数值计算

推荐目录：系统示意与坐标 → 物理假设 → 变量及单位 → 方程逐步推导 → 初始/边界/接触条件 → 参数标定 → 离散或求根方法 → 关键状态/曲线 → 交叉检验 → 工况扩展/优化。

必须把“正问题”和“反问题”分清：已知参数算观测，还是由观测估参数。反演问题还要说明是否多解、是否依赖初值，以及用何种附加信息缩小解集。多阶段工况用分段条件连接，写出边界处的连续或跳变关系。

原创推导骨架：

> 将〔对象〕划分为〔单元/阶段〕，依据〔定律〕列出〔方程〕；以〔条件〕闭合方程组。由〔数据〕估计〔参数〕后，使用〔数值方法和精度控制〕求解。通过〔独立关系/步长变化/已知极限〕检查计算，并比较〔观测〕与〔预测〕的〔误差指标〕。

同题差异：2016 A 力学稿按节点递推并换取矩点检查，多目标稿用悬链线与刚体方程汇总再搜索设计；2020 A147/A195 都从热传导走向工艺优化，但标定、假设与数值结果不同。应学习“机制→计算→设计”的主线，不能把某稿给出的参数作为材料常数。[P18、P19、P11、P12]

状态到目标的接口示例：2022 A001 先呈现位移与速度响应、题目指定时刻表，再定义平均功率用于设计优化。由动力学走向优化时，正文应显式交代状态量如何进入目标、积分时段如何选择，以及暂态是否排除。[P31；后两项为蒸馏后加强要求]

## D. 评价与排序

推荐目录：评价目的与对象 → 指标选择的业务依据 → 指标方向/尺度/相关性 → 缺失处理 → 权重与聚合规则 → 得分/分级 → 驱动因素 → 稳定性及决策应用。

先写“评价什么、为谁评价”，再引入方法。指标数量增加不自动提高质量；重复指标会重复计权。离散程度大的指标不天然更重要，数据驱动权重也需要说明其含义。没有可信标签时不要报告预测准确率来证明排名“客观正确”。

原创解释骨架：

> 指标〔A〕描述〔任务相关性质〕，指标〔B〕反映〔另一性质〕；因〔可获得性/冗余〕，未纳入〔候选指标〕。统一方向和尺度后，采用〔权重来源〕得到综合得分。对象〔X〕排名较高主要源于〔指标贡献〕。权重在〔范围〕变化时，前〔k〕名中〔稳定性结果〕，因此推荐〔有条件决策〕。

同题差异：2021 C085 已读页用熵权得分衔接供应商选择；C169 用投影寻踪构建供货能力评价。两者的可迁移共性是“评价服务后续采购约束”，不是评价公式本身。1993 足球材料先立保序/稳定/缺失处理的标准，给出了评价问题更深的写法。[P08、P09、P28]

## E. 随机过程与仿真

推荐目录：决策视角与已知信息 → 状态和事件 → 随机量分布及来源 → 状态转移/行为规则 → 仿真流程 → 校准及重复设计 → 多情景结果 → 决策阈值 → 时长/分布/策略敏感性。

明确单位时间和统计口径；仿真规则应能逐步手算小例。报告重复次数及不确定性，不能只取一次最好结果。待验证规则不能用同一规则生成的数据自证真实；可在模型内部检查一致性，但要明确证据层次。

原创比较骨架：

> 在〔同一输入和随机设计〕下，对〔各方案〕各运行〔次数〕次，记录〔均值、区间、失败率〕。方案〔A〕在〔情景〕下更优，但当〔参数〕超过〔阈值〕时推荐切换为〔B〕。该阈值依赖于〔分布或行为假设〕，实际应用前需以〔观测〕校准。

同题差异：2019 C044 以两种司机决策的预期利润比较为主；C137 还按车多/人多等情景解释上车点效率并检查仿真时长与权重。2020 B078 依次区分已知天气、随机天气和多玩家情形。应迁移信息结构和情景组织，不迁移历史阈值。[P16、P17、P13]

## 最终选择检查

章节不是模型名称目录。读完每问应能回答：输出是什么、为什么这样建模、结果从哪里来、在哪些条件下成立。若混合了两个原型，画出前者输出传给后者的接口；把预测误差或评价不稳定性继续传入决策层，避免前端不确定、后端假装精确。
